# Gate ratified — `mpe_check` becomes blocking

**Date:** 2026-08-09
**Trigger:** human — *"Gate ratified."* (`./verify` is a protected path; this is
the approval requested in PR #242.)
**Verify:** `./verify full` GREEN, **15 gates**. Proven red at the dispatcher:
exit **1** with the fan-out bug planted, exit **0** restored.

## What changed

One line in `full()`:

    "$build_dir/mpe_check" || return 1

placed with the other plugin-level probes, plus the reasoning in comment form
(why audio detection rather than a state read, and what the calibration was).

`CLAUDE.md` §Domain said "eight oracle chains" and was stale by seven — glide,
time, and every behavioural probe had been added without it being updated.
Corrected to fifteen, split honestly into nine parity/trajectory chains and six
behavioural probes, since those are different kinds of claim.

## Proven at the gate, not just at the probe

Reverting `allOffAll()` to `cores[0].allOff()` in the note-off path:

| | probe output | `./verify full` |
|---|---|---|
| bug planted | `rms 0.142 → 0.142 → 0.142, decay ×1.0` | **exit 1** |
| restored | tail decays to 0 | **exit 0** |

The distinction is the whole point. A probe that prints RED while the
dispatcher swallows its exit code is exactly what stranded the oscillator
preset tier: main stayed green because the missing piece WAS the gate. Checking
`mpe_check` alone would have re-run that mistake in a new costume.

## Why this gate earns its seconds

The fan-out class was invisible to all fourteen other gates, and not by
accident: **parity renders a single core.** The bit-parity oracle — the
project's strongest instrument — is structurally blind to any bug that only
exists when there are two oscillators. A bend that split the oscillator pair
and an all-notes-off that left half the instrument gated both passed everything.

This also makes a debt visible. The shipped fix is a helper per operation
family, so every future consumer (third oscillator, sub-oscillator, per-voice FX
send) re-opens the whole class until the L0029 routing layer lands. The gate is
what turns that from a silent regression into a red build.
