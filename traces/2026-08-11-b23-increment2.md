# B23 increment 2 — the routing matrix enters the audio path

**What changed.** `RoutingMatrix<1, kRackSlots>` now drives the FX rack in the plugin's
`process()`; the direct `rack.processStereo` call is gone. `processSlot()` extracted from
`processStereo` (mechanical, switch body untouched); `processBlock()` added to `routing_core.h`
(block-stereo forward pass, caller-owned scratch); shell wiring uses fixed stack scratch and a
`kMixChunk` loop. `RoutingMatrix()` now establishes the serial chain, because the zero state means
silence.

**Why one source and not per-oscillator.** Per-oscillator sources force bass-mono downstream of the
rack. The justification for that reorder — a decorrelating slot undoing the mono guarantee — was
measured and refuted: Comb at 0.9 scales the sub-crossover channel difference 2.2x with bass-mono
on OR off (residual 10.6% vs 11.4%); it is stereo-symmetric. No slot type decorrelates today, so the
reorder had no correctness case and was refused.

**Evidence consulted.**
- `src/hypersaw_clap.cpp:1527` — the recorded reason for stack scratch over an activate()-sized heap
  buffer (a restored instance silently lost oscillator 1; state_check caught it).
- `src/routing_core.h` header note — why topology logic must not be duplicated in a consumer.
- Ad-hoc Goertzel probe on the plugin (scratchpad) for the bass-mono measurement above. Its first
  version used a 6 dB/oct low-pass and failed a working crossover; L0032 again.

**Oracle.** `./verify full` GREEN, fifteen gates. parity 147/147, worst 4.262e-09 @ dyn-ring.seed42.
`routing_check` GREEN including new assertion 8 (serial-chain block pass == `rack.processStereo`,
0/1024 samples differ, four active distinct slots, reference energy 172.3). `rtsafety_probe` clean,
block sizes 33..2048.

**Calibration.** Assertion 8 fires (1023/1024) on a 1e-6 coefficient error and on zeroing the output
before the gather (the documented aliasing hazard). It is a NO-OP on removing the `isTerminal`
filter — `setSerialChain` zeroes `outAmount` on non-terminals — so assertion 8 does not cover
terminal detection; assertion 4 does. Recorded in the source.

**Caveat carried forward.** The 147 goldens render `SwarmCore` directly and are blind to the entire
plugin mix stage. Parity green is not evidence about this change; assertion 8 is.
