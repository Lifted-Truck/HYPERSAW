The defect

The earlier crash fix guarded the read index but still derived frac from the un-wrapped rd. The exactly-len case then gave i0 = 0 with frac = 8192 — no NaN, but an 8192× interpolator extrapolation. Captured live at the failing sample of K3 → choDep: neighbours -0.13589 and -0.13212 produced v = 30.73, and the chorus stage output 8.99 against a synth peak of 0.49. Every hot cell above is a choDep routing, which is what localized it.

Still open — one dead routing (design question, not a bug)

R → Kboost at positive depth is bit-identical to no routing. Kboost is half-wave rectified (8 * max(0, kbMod)) and R is mapped bipolar (R*2-1); below the coupling knee the swarm never locks, so the source is always negative and the rectifier zeroes it. It revives exactly where R crosses 0.5:
