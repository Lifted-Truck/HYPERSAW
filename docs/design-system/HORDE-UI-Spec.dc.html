§5 WORDMARK — GENERATIVE WARP + MORPH LETTER-FLIP
glyphs "horde" · Archivo 800 · letter-spacing −0.02em field 2-octave fractal noise · base frequency 0.010 x / 0.016 y (per CSS px at 76pt) displace 52px at 76pt — scale strictly ∝ point size (22px header mark ⇒ scale 22/76·52 ≈ 15) reseed per plugin launch (NOT per frame, NOT per render) · seed is uint32, logged to state colour morph inactive: solid ink morph active: each letter is a lottery member — fill = owning corner's DARK pair (#D4A900/#FF2E88/#00B3A8/#6FB200); reassign ONLY on a real flip event, one letter per event, same hysteresis as params; morph off ⇒ all ink again budget warp computed ONCE per seed; letter recolour = fill swap on the cached run
