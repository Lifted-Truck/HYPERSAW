SCALE root C ▾ major (ionian) ▾ GLOBAL OFFSET
GLOBAL mode — pitches are PLACES, so it looks like a piano
C ★ D E F G A B
OFFSET mode — intervals are DISTANCES, so the piano flattens into dominoes from the note you play
▶ played1 b2 2 b3 3 4 b5 5 b6 6 b7 7
The solve: ONE control, two skins, and the SKIN is the mode indicator. GLOBAL keeps real piano geometry (black keys raised, note names, root starred yellow) because pitches are fixed places. Flip to OFFSET and the same 12 cells lose the black-key geometry and note names entirely — equal dominoes, interval labels, and the first cell becomes the magenta "▶ played" puck, so nothing on screen claims to be a C. Same hit targets, same toggle interaction, zero relayout; the eye learns "piano = absolute, dominoes = relative" in one flip. Bonus honesty: in OFFSET the root selector greys out (it has no meaning there), which is the second cue for free.
Placement in 6a: BEND replaces the ENV slot's lower half in the left column (ENV shrinks to a strip) or MAIN grows a fourth row — say which and I'll recompose. Scale cells toggle on click; magenta stays reserved for the played-note puck and the actual bend curve — both are "your hand", which is exactly what magenta means.
