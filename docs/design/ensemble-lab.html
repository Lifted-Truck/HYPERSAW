Task #25 — per-voice onset scatter, generated by mutual error correction rather than by jitter. The 2026-07-28 research found listeners judge ensemble togetherness from the serial structure of onset asynchrony (its lag-1 autocorrelation, set by inter-player correction gain), not from its variance — so i.i.d. per-note randomness, which is what every "humanize" control does, is the wrong mechanism. Coupled onset scatter

Raster: one row per note, one dot per voice, horizontal = its onset offset. α is the mechanism, not a humanize amount: 0 = nobody corrects (offsets drift apart), ~0.25 = the value reported near-optimal for real quartets, 1 = full correction every note (that is what jitter sounds like), >1 = over-correction, the group fighting itself.

Measured — live

Both quantities the research names. Onset SD — real professional ensembles sit at 24–73 ms, discrimination threshold ~8 ms. Lag-1 autocorrelation — the serial structure listeners actually judge; it should FALL as α rises. If moving α changes the autocorrelation while SD stays put, the mechanism is doing what the literature describes.

Tuning & attack

Character is bidirectional because bowed attacks fail in two different ways: + scratchy (over-force, string sticks), − loose (under-force, multiple slipping, longer settling). Spectral smear disperses each voice's formant position — an axis the research found INDEPENDENT of pitch scatter, so it thickens without detuning.
Detune is now a gaussian σ in cents, because that is what the literature measures. Research target: 5–15 cents SD — listeners preferred 0–5 and set the ceiling at ~14. Far tighter than a supersaw: the variation belongs in time, not tuning.
