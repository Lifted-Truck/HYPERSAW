SWARM✱ · shape lab

Campaign-2 item 6 — the three phase-domain axes from the 2026-07-25 timbre research, prototyped together because they share one aliasing budget. Every axis keeps the waveform a rising ramp per cycle, so the saw mandate holds: sync resets the ramp early, warp changes its rate, ripple perturbs it. Nothing here replaces the sawtooth with another waveform. Audition lab, spec-in-code — NOT a reference. Live-style keys: ASDFGHJKL whites · WE · TYU · OP blacks · Z/X octave · space drone.

Axis 1 — hard sync

−136 dB vs −62 dB alias
Ratio 1 = inert (plain saw). ← coupling is the differentiated control: a₁ tracks the swarm's order parameter R, so the stack gets harder as it locks and softens as it splays — sync driven by the physics, not by an LFO. Spread gives each voice its own ratio.

Axis 2 — phase warp (formant)

d = v is a plain saw. Moving them apart makes the ramp run fast then slow (or the reverse) — still a monotone rising ramp, so still a sawtooth, but the slope break puts a formant peak in the spectrum. Not a filter: position and bandwidth are set by the same two numbers, so they cannot be dialled independently — which is why this is drawn as a phase map, not a resonance knob.

Axis 3 — ripple

A bounded sinusoidal perturbation of the phase — the continuum of subtle sawtooth variants that retargets ADR-058's saw↔square morph. Depth is capped so the ramp stays monotone (a fold would stop it being a saw).

Swarm

anti-alias 1 = polyBLEP on, 0 = naive. Flip it while a high note sounds — the difference is the whole reason the sync axis needs a BLEP budget.

Shape & spectrum

Coupling: each dot is a voice's phase on the circle; the white arm is the order parameter R (length = how locked the swarm is, angle = mean phase). K>0 clumps them, K<0 splays to an even polygon, K=0 drifts. When ← coupling is up, the a₁ readout moves with R — that is the swarm driving the sync.
