Each voice is an independent singer — own fundamental, own grain train, own register state R (the bar height in each cell). choir K couples the voices' formants toward the ensemble mean: at 0 they are separate singers, turned up they agree on a vowel the way the swarm agrees on a phase. poly trim divides by √(voice limit) before the drive stage — the reference is mono, so its drive was tuned for one voice and a six-note chord otherwise pins the tanh (measured: 1 voice peaks 0.84, 6 peak 1.00). Trim follows the LIMIT, not the live count, so notes never duck each other. Set it to 0 to hear the reference's summing.

Every formant is voiced by copies grains at ±detune, panned apart. The beating lands inside the formant rather than on the fundamental, so the vowel shimmers while the pitch stays solid. spread curve < 1 bunches the copies at the edges (two-sided chorus), > 1 crowds them at centre. Level is compensated by 1/√copies, so the control is width, not loudness.
