Shape Lab — LFO / envelope builder

One breakpoint editor for both. Drag points · double-click to add · right-click to delete · drag the mid-segment handle to bend the curve. Time is normalised 0–1; rate/duration are separate.

Editor — envelope

Segment curve = one exponent per segment (bipolar tension), so the audio-thread evaluator is a single pow(). Sustain point (envelope mode) is the marked breakpoint; release plays from it on note-off.

Output as the core would consume it

Sampled at the chosen control rate over 2 cycles / one note. Coarser rates show the stepping the core would actually apply — this is the honest picture, not the pretty one.

Mode
